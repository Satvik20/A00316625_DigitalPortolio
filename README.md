# Nagasai Chintalapati — Digital Portfolio

Personal portfolio for Nagasai Chintalapati, an AI-focused software engineering student at the Technological University of the Shannon (TUS).

**Live site:** https://satvik20.github.io/A00316625_DigitalPortolio/

## Pages

- `index.html` — portfolio: selected work, projects, experience, and about me
- `storyboard.html` — elevator pitch video and five-part script

## Run locally

Open `index.html` in a browser. To play the embedded YouTube video locally, serve the folder over HTTP:

```sh
python3 -m http.server 8000
```

Then visit http://localhost:8000.
